# 5.2 迷宮ギルドUI

`src/features/guild/Guild.tsx` を共通シェルの保存済みguild現在地へ接続する。編成・プリセットは候補を編集し、「変更を保存」でGameState.updateへ渡す。保存成功までは確定Storeを変更しない。変更取消は確認ダイアログを出す。保存失敗はセーブ管理の同候補再試行／放棄へ接続する。編集中は設定や別画面への遷移とワープを禁止する。

## 編成とスキル

3人の選択、全8ジョブの切替、A／B各3ノード、未習得・予算不足の性能閲覧を提供する。ジョブ変更は本人の全スキル解除を確認してchangeJobを呼ぶ。同職の別人物編成を許可する。learnSkill、getSkillRefund／removeSkill、resetSkillsを使い、前提を失う子孫と返却ポイントを確認できる。

getGuildBuildDetailsから装備反映後の能力、初期待機、費用・前提・置換・習得可否、詠唱・基礎D・現装備D・CD共有・属性候補・全効果と付随効果を表示する。回復などの参考値は状態補正なしの独立効果と明記し、対象等が未指定のダメージを0や確定予測として表示しない。判定・計算式をUIで重複実装しない。

## 宝物庫と18装備枠

EquipmentPanelは全編メタデータからgetInventoryを照会し、収録品と所持済みの未収録品を表示する。所持・装備中・残りを分け、未所持や残り0の宝物庫品を装着不可にする。人物の全6枠を表示し、タップ／キーボードによる選択・交換・解除と、宝物庫／枠からのドラッグを提供する。

setEquipmentとtransferEquipmentのswapで候補を作る。所持数や遺物のユニーク制限は既存検証APIへ委ね、外部ドラッグの不正な形式を取り込まない。交換は2枠を一括更新し、品を破棄しない。

## プリセット

PresetPanelは最大20件の登録・改名・上書き・呼出・削除を既存プリセットAPIへ接続する。名称入力は登録・改名で候補へ反映し、最後に変更を保存する。上書き・呼出・削除は確認付き。管理ID・作成日時を保持し、更新日時順に一覧を表示する。

無効な旧編成も原本を保持して表示する。通常呼出を無効にして理由を表示し、previewPresetRepairの差分・残存問題を確認する。適用可能な場合だけrepair付きrecallPresetで現在編成候補へ呼び出す。旧プリセット自体は変更しない。構造不正の編成も画面例外にせず、修復不可の案内と削除・上書きの選択肢を提供する。

## 伝言板とワープ

全10階層の一覧、テーマ・入口文・ヒント、未解放／解放済み／解放済み・この版では未実装を表示する。warpToFloorで候補を作り保存成功後に探索現在地へ切り替える。現在地の「拠点へ帰還」もreturnToGuildを保存する。保存失敗中は移動せず、再試行成功後だけ移動先を表示する。編成の編集・保存中、休止・読取専用、戦闘中は編集・移動を禁止する。

## 検証と後続接続

Guild.test.tsxはジョブ変更と本人だけの解除、連鎖返却・再習得、取消、保存失敗再試行、18枠のタップ交換・ドラッグ候補拒否・再装着、プリセット管理・20件制限・旧版修復・構造不正の原本保持、ヒント・ワープ・帰還・ワープ保存失敗・未収録階層を検証する。PCと幅320pxのブラウザで、検証用カタログを使ってギルド・装備画面を表示し、横スクロールがないことを確認した。検証用の一時エントリは成果物から除去済み。

背景はCSSの仮アセット。完成アートは6.3で置換する。公開起動は引き続き正式GameReleaseと配信準備を待つ8.2の対象で、合成fixtureを製品へ組み込まない。ワープ後の探索描画・経路移動・遭遇は5.3へ接続する。
