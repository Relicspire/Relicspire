# 1.3 Relicspire 全10階層のコンテンツ

本書は [開発タスク](./tasks.md) の1.3に対応する。[ゲームルール](./game-rules.md) と [成長・編成・報酬](./growth-party-rewards.md) を適用し、全10ボス・50守護者の具体値、行動列、配置、報酬、ヒント、終了後の進行を定義する。値は採用する設計値であり、実装後の全編バランス検証を完了した意味ではない。

## 1. 探索と進行の共通仕様

### 1.1 経路と遭遇

各階層IDは `floor-01`～`floor-10`。ノードIDは階層IDに以下の接尾辞を付ける。全階層で同じ接続構造を使い、名称・背景・敵だけを各階層表から設定する。

| 接尾辞 | 機能 | 双方向の接続先 |
| --- | --- | --- |
| entry | 入口・ワープ着地点・帰還口 | hall-1 |
| hall-1 | 第1分岐 | entry、hall-2、alcove-1、alcove-2 |
| hall-2 | 第2分岐 | hall-1、hall-3、alcove-3、alcove-4 |
| hall-3 | 第3分岐・ボス予告碑 | hall-2、boss、alcove-5 |
| alcove-1～5 | 守護者1～5の任意遭遇 | 1・2はhall-1、3・4はhall-2、5はhall-3 |
| boss | ボス遭遇・討伐後の出口 | hall-3 |

- 主経路はentry→hall-1→hall-2→hall-3→boss。鍵・守護者討伐・遺物・イベント既読を通行条件にしない。
- 各alcoveの名称は「その階の遺物名＋の祠」。1・3は左の枝、2・4は右の枝、5は奥の枝として表示し、主経路は「進む」で選べる。
- 移動は1辺ずつ即時確定する。実時間・TU・歩数による消耗、迷路ループ、罠ダメージ、ランダム遭遇はない。
- 生存敵の部屋では敵の全能力・行動列・報酬を表示し「戦う／回避して戻る」を選ぶ。接触だけでは戦闘を開始しない。
- 討伐済みIDの敵は表示せず、部屋に討伐済み表示を残す。再戦・報酬再取得は不可。守護者の祠からは親分岐へ戻る。
- 戦闘前探索位置は親分岐として保存する。敗北・逃走でそこへ戻り、勝利時は敵の部屋へ移動する。戦闘再読み込みも遭遇前から再開する。
- 戦闘外ならどのノードからも拠点帰還できる。拠点から解放済み全階層のentryへワープ可能。帰還・ワープ・編成変更に費用はない。

### 1.2 階層解放・イベント

- 新規開始ではfloor-01のみ解放。boss-N討伐でfloor-(N+1)を解放し、既存階層は閉鎖しない。
- 各entryで初訪問の短文、hall-3でボス予告碑を表示する。閲覧は任意で、再閲覧可。初訪問文は各階層見出しの「入口文」をそのまま用いる。
- 予告碑とギルド伝言板は同じ階層別ヒントを使う。階層解放時に全ヒントを解放し、追加の取得条件や隠しヒントはない。
- ボス勝利後は「拠点へ戻る／探索を続ける／次階層へ」を選べる。次階層へは次のentryへ直接移る。第10階層では次階層の選択肢はなくエンディングへ進む。
- 討伐済みボスの出口は、未討伐守護者が残っていても利用可能。未解放階層への逆抜けは不可。
- 報酬は1.2の表に固定し、勝利時にのみ討伐済み・所持品・ポイント・解放を一括更新する。

## 2. 敵データ・行動列の共通仕様

同時刻処理・定期効果によるフェーズ移行・行動終了時の予定更新はゲームルール11.1～11.5節に従う。全遭遇は同11.7節の今回実装範囲に収める。

- 全遭遇は敵1体のみ。召喚・増援・蘇生・隠しフェーズはない。初期HP・ゲージは最大値、状態効果なし、CD0、行動列の先頭から開始する。
- HP、ATK、MAG、DEF、MDEF、SPD、ゲージ、弱点、耐性を各表で定める。弱点と属性耐性はそれぞれ1属性。無属性を含む他属性は通常、無効属性なし。
- 全敵のブレイク耐性・後退耐性は0、詠唱キャンセル無効・時間停止無効はfalse。ブレイクはゲージ0で発生し、60 TU後に満タンで復帰、さらに `ceil(10000 / SPD)` TU待つ。詠唱中以外も同じ削りが有効。
- スキル表の威・回・D・詠唱・状態系統・丸めは既存仕様に従う。敵の攻撃の削りは0、記載のない妨害は0、攻撃は1ヒット、全敵スキルのCDは0。スキルIDは敵ID＋`-s1`など。
- 「最低HP」は生存味方の現在HPが最小、「最高SPD／ATK／MAG」は現在の最終能力が最大。比率ではなく数値で比較し、同値ならparty-1→2→3。挑発は単体対象に適用する。
- 全体は生存味方全員、自身は敵自身。回復・軽減・強化も各敵自身を対象にする。毒・能力弱体・軽減・強化は1.2の共通familyIdを使い解除可能。
- 行動列は左から開始し末尾の次は先頭へ戻る。各開始で列を消費し、キャンセル・開始前ブレイクによるスキップもゲームルールどおり。罠による延期では消費しない。
- フェーズ移行は処理単位末尾にHP条件を評価し、一度移ったら回復しても戻らない。移行時に新列の先頭へ設定する。既存詠唱・待機・CD・ゲージ・状態は維持し、移行演出だけでは新しい手番を得ない。移行中の詠唱が完了しても新列を追加消費しない。
- 常時、敵の数値HP、ゲージ、属性、耐性、全スキル性能、全行動列、全移行条件を閲覧可能にする。次のスキル・対象・開始TU・詠唱完了TUをバーに表示し、次フェーズも隠さない。
- 守護者のフェーズ変更はなし。ボスの移行は各階層の定義だけ。フェーズで変わるのは行動列のみであり、能力・弱点・耐性・ブレイク条件は変えない。

- 全10階層は引き続き再訪可能。未討伐守護者を倒し、未取得遺物を回収できる。討伐済みボス・守護者は再出現せず、新しい階層・周回・隠しボス・追加ポイントはない。
- エンディング閲覧済みは演出管理用フラグとして別に保存する。勝利保存後・閲覧前に終了した場合、次回起動時に「エンディングを見る／拠点へ」を選べる。クリア報酬は再付与しない。
- 新規ゲームは現在セーブの上書きを明示して確定した場合のみ開始する。クリア後に自動リセットしない。
