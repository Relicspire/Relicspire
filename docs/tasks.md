# Relicspire 開発タスク

本書は [`plan.md`](./plan.md) を実装可能な作業単位へ分解したタスクリストです。上から順に進めることを基本とし、仕様変更時は関連するデータ、テスト、ドキュメントも同時に更新します。

## 0. 完成条件（Definition of Done）

- [ ] PC・モバイルの主要ブラウザで、拠点から第10階層クリアまで進行できる
- [ ] 3人編成、8ジョブ、各2系統のスキルツリー、6装備枠、プリセットが機能する
- [ ] 全10階層に階層ボスを実装し、各階層の任意の遺物守護者とユニーク遺物を実装する
- [ ] 完全情報型タイムラインのターン制戦闘、ディレイ、クールダウン、詠唱妨害、ブレイク、バフ／デバフ、戦闘不能／蘇生が仕様どおり動作する
- [ ] 勝利報酬、討伐済みフラグ、階層解放、セーブ、ロード、セーブデータ移行が機能する
- [ ] 敗北・逃走・再挑戦に恒久的なペナルティがない
- [ ] 初回読み込み後、必要なゲームアセットをオフラインで利用できる
- [ ] 自動テスト、型チェック、Lint、ビルドが通り、GitHub Pagesへ自動デプロイできる
- [ ] セーブ破損、進行不能、操作不能、再現性の高いクラッシュが残っていない
