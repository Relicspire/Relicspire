# Relicspire 開発タスク

本書は [`plan.md`](./plan.md) を実装可能な作業単位へ分解したタスクリストです。上から順に進めることを基本とし、仕様変更時は関連するデータ、テスト、ドキュメントも同時に更新します。

## 0. 完成条件（Definition of Done）

- [ ] PC・モバイルの主要ブラウザで、拠点から第10階層クリアまで進行できる
- [ ] 3人編成、8ジョブ、各2系統のスキルツリー、6装備枠、プリセットが機能する
- [ ] 全10階層に階層ボスを実装し、各階層の任意の遺物守護者とユニーク遺物を実装する
- [ ] 完全情報型タイムラインのターン制戦闘、ディレイ、クールダウン、詠唱妨害、ブレイク、バフ／デバフ、戦闘不能／蘇生が仕様どおり動作する
- [ ] 勝利報酬、討伐済みフラグ、階層解放、セーブ、ロード、セーブデータ移行が機能する
- [ ] 敗北・逃走・再挑戦に恒久的なペナルティがない
- [ ] 初回読み込み後、必要なゲームアセットをオフラインで利用できる
- [ ] 自動テスト、型チェック、Lint、ビルドが通り、GitHub Pagesへ自動デプロイできる
- [ ] セーブ破損、進行不能、操作不能、再現性の高いクラッシュが残っていない

### 1.4 戦闘仕様の境界条件・文書間の整合

- [x] 同じ参加者の同時刻イベントの優先順を確定する。ゲームルール2.2節の「期限切れ・時間停止解除・ブレイク復帰」の内部順、解除後に残り0 TUの予定が戻った場合、定期効果でフェーズ閾値を越えた場合の評価時点を定義する
- [x] 手番到達済み・基本行動の処理中の参加者への時間操作を定義する。ゲームルール3.3節は待機・詠唱への後退だけだが、育成仕様2.9節は行動可能への後退も許可している。罠・反撃から受けた後退が行動終了時のディレイ設定で失われないよう、予定の更新・加算規則を統一する

- [x] 時間停止中の再付与・解除・死亡を定義する。凍結中の通常効果へ `now + 持続TU` を上書きする6節と残りTU保存の7.5節を整合させ、同時刻の停止解除と効果期限、停止中の詠唱キャンセル、死亡時に残るCDの復元を例で固定する
- [x] 複合スキルと全体効果の対象・適格性の判定時点を統一する。ゲームルール4節の発動時全体対象と7.1節の効果ごとの対象確定について、効果途中の死亡・蘇生、聖断などの自身効果、かばう対象への攻撃後に別効果として付く毒・解除の対象をEffectモデルへ移せる形で定義する
- [x] 能力値の参照時点を固定する。ゲームルール3.3節の「発動時SPD」を効果適用前／後のどちらとするか決め、加速の陣で自身を強化した直後のディレイ、聖断・反撃・追撃・罠の威力計算で参照する能力と効果残量を定義する
- [x] 属性無効・バリア・固定HPダメージと付随効果の成立条件を定義する。無効属性へのキャンセル・弱体・強化解除の可否、HP損失0時の反射回数消費、反射後に攻撃者が倒れた場合の反撃を明記する
