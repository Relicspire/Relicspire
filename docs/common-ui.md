# 5.1 共通UI

共通シェルは `src/app/App.tsx`、起動管理は `runtime.ts` と `main.tsx`、復旧操作は `SavePanel.tsx`、設定編集は `SettingsPanel.tsx` が担当する。

## 起動と後続タスクへの接続

製品は `src/content/release.json` をViteで同梱し、`parseGameRelease` で検証する。所有権取得、SaveRepository生成、GameState生成、loadの順で起動する。再確認では所有権を再取得して最新セーブを読み、古い戦闘を破棄する。pagehideで所有権を解放し、BFCache復帰は再読込する。所有権変更の通知で戦闘・遭遇を破棄し、読取専用へ移す。

正式カタログは5.5で未制作。タスク8は `VITE_BUILD_ID` を供給し、全必須ファイルの検証後、初回だけ配信状態キーを原子的に確定する。共通UIはキーを書き換えず、現在のbuildIdとの一致を読み取る。キャッシュ照合はタスク8の責務なので、キー一致だけで「オフライン利用可能」とは表示しない。タスク8完成時には検証済み配信状態を共通UIの開始条件へ接続する必要がある。現在はデータがない場合に準備待ちを表示し、データがあっても配信キー不一致なら初回開始・設定保存を禁止する。既存保存は読込・書出し可能。

合成リリースはUI自動テストにのみ使用し、公開起動へ取り込まない。5.1の製品起動と実タブ所有権の統合確認は、正式データ・配信機能の完成後に行う。

## 操作と保存境界

保存中・読込中は操作を禁止する。設定は候補を編集し、確定時にGameState.updateを呼ぶ。取消では確定値を維持する。保存失敗時は表示候補を確定値へ戻し、保存管理器の同じ候補を再試行または確認付きで放棄できる。ロード失敗には書込再試行を出さず、再読込を提示する。未保存候補がある間は再読込による候補破棄を許可しない。

復旧の差分一覧と確定、previousの巻き戻り確認、新規開始の上書き確認、未保存勝利の放棄確認、生データJSON書出しを接続する。未来版は新版への案内と原本書出しを提供し、上書き操作を隠す。既存設定は新規開始でも保持する。

現在地は保存したguild／探索ノードから表示する。共通メニュー、Escape／Alt+左、popstateは保存・編集中・確認ダイアログ中の遷移を止める。ブラウザ履歴には同一URLのアプリ内戻る用エントリを置く。ブラウザ終了の防止は保証しない。実際の探索移動、遭遇、戦闘中の戻る選択、敗北・勝利の遷移は5.3～5.4で接続する。

## 休止とアクセシビリティ

非表示で休止し、復帰後も「再開」を押すまで維持する。保存中の処理は完了させる。所有権喪失時は休止解除とは別に操作を禁止する。

共通シェルは `document.documentElement.dataset.paused` と `reducedMotion` を公開する。現在はCSS演出を停止・抑止する。PixiJS・音声の停止、音量・演出速度・スキップ・揺れの適用は5.3～5.4の制御側が同じ状態に従うこと。設定値そのものやTU計算を変更しない。現時点で音声・戦闘描画は未接続。

幅320px以上のレイアウト、44px以上のボタン・入力、可視フォーカス、本文スキップ、フォームラベル、モーダルのTab循環・Escape取消・終了後フォーカス復元を用意する。端末のprefers-reduced-motionを監視し、保存設定は変更せずCSSの動きを抑える。エラー境界は画面例外で操作停止と保存済み状態からの再読込を案内する。

## 検証

`src/app/App.test.tsx` は初回開始の配信待ち、設定確定と再読込、取消、容量不足の再試行、未来版拒否、previous確認とEscape取消、非表示からの手動再開、所有権喪失の操作禁止を検証する。既存保存層テストが保存・復旧・競合の原子的保証を担当する。

実ブラウザの複数タブ、正式データでの起動、探索・戦闘と演出の統合確認は5.5／7.2で行う。
