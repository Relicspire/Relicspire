# 探索UIの接続契約

`src/features/exploration/Exploration.tsx`を共通UIの探索復帰先へ接続する。正式リリースと配信準備の起動ゲートは維持する。テスト用カタログを製品へ組み込まない。

## 保存と遭遇

- `game.move`・`warp`・`returnToGuild`・`nextFloor`は既存の純粋な進行APIで候補を検証する。通常移動の現在地・初訪問フラグは書込成功後にだけ配布する。
- 初訪問本文も保存成功コールバックで設定し、保存失敗の再試行で表示する。取消では初訪問を消費しない。本文・ヒントは再訪時にも読み直せる。
- 生存敵の部屋を選ぶと一時的な遭遇確認を表示し、位置・保存世代は変更しない。回避は確認だけを解除する。討伐済み敵の部屋は通常移動になる。
- 戦う操作は`startBattle`へ接続し、戦闘前保存の成功後だけ戦闘セッションを生成する。失敗時は共通セーブ管理の再試行・取消へ戻れる。
- 戦闘操作の完成は5.4。現在は戦闘開始済みの案内と、保存済み親分岐へ戻る操作を提供する。
- 再読込で一時遭遇・戦闘を解除し、保存した現在地から再開する。休止・所有権喪失・保存中は移動を禁止する。

## 描画

PixiJSのApplicationをReactのEffectで初期化・破棄する。非同期初期化中のアンマウントも生成完了後に破棄する。描画は確定位置・遭遇・設定だけを受け取り、進行判定やロジック時間を変更しない。

仮の主観通路・敵シルエットはGraphicsで描く。移動後の短い前進演出は設定の速度に従い、休止と端末の動きを減らす設定で停止する。ResizeObserverで再描画し、WebGL喪失時はTickerを止めて案内する。描画非対応でもDOMの経路ボタンで続行できる。完成アセットへの置換は6.3。
